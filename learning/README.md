# Learning Docs

This folder holds a step-by-step record of how the project was built, for re-reading later without getting lost.

## Layout

```
learning/
  01_repo_setup/
    01_install_project.md
    02_installing_dependencies.md
  02_backend_setup/
    01_project_setup.md
  03_documents_ingestion/
    01_pdf_ingestion_chunking.md
  04_rag_pipeline/
    ...
```

- One subfolder per topic, numbered in the order topics were first introduced: `NN_topic_name/`. New topics get added as the project grows — the list above isn't fixed.
- Inside a topic, files are numbered in the order the steps happened: `MM_description.md`.
- Each file is short, plain language, and says **what** we did and **why** — with a small diagram if it helps.

See [`../docs/PROJECT_FLOW.md`](../docs/PROJECT_FLOW.md) for when these docs get written (before each task) and rechecked (after).
